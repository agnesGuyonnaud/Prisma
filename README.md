## Instrucciones

## Google Calendar
- Habilita Google Calendar API en el proyecto de Google Cloud asociado a las credenciales OAuth de la app.
- Configura la pantalla de consentimiento OAuth para el alcance `https://www.googleapis.com/auth/calendar.events`.
- El permiso se solicita desde el perfil. Las tareas se sincronizan en una sola dirección como eventos de una hora; al desactivar la sincronización, los eventos existentes permanecen en Calendar.
